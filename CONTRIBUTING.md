# Contributing

Thank you for improving ProxyCache.

- Create branches as `feature/short-description`, `fix/short-description`, or `docs/short-description`.
- Use concise imperative commits, for example `feat: add cache metrics` or `fix: respect no-store`.
- Run `npm run lint` and `npm test` before opening a pull request.
- Keep pull requests focused, describe the behavior change, and include tests for new behavior or regressions.
- Do not commit `.env` files, credentials, or generated dependencies.
